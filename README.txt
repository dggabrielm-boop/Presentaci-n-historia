PRESENTACIÓN INTERACTIVA · UNA ISLA A 145 KM DE FLORIDA

Cómo verla
1. Abre index.html con Chrome, Firefox, Edge o Safari.
2. Para publicarla, sube esta carpeta completa a GitHub Pages.

Cómo editarla
- Textos, preguntas, respuestas, títulos e imágenes: slides.js
- Colores, tipografías y composición visual: style.css
- Estructura general y controles: index.html
- Lógica de navegación, cuestionarios y resultado: app.js
- Recursos visuales: carpeta assets

Cambiar una imagen
1. Copia la nueva imagen dentro de assets.
2. En slides.js reemplaza, por ejemplo:
   image: "assets/map-cuba-florida.png"
   por:
   image: "assets/mi-imagen.png"

Cambiar una respuesta correcta
En cada pregunta, correct usa numeración desde cero:
- correct: 0 = primera opción
- correct: 1 = segunda opción
- correct: 2 = tercera opción
- correct: 3 = cuarta opción

Publicar en GitHub Pages
1. Crea un repositorio público.
2. Sube todo el contenido de esta carpeta a la rama main.
3. Ve a Settings > Pages.
4. En Source selecciona Deploy from a branch.
5. Elige main y / (root), luego Save.

La presentación es autocontenida. Solo el video de YouTube y la opción de
abrirlo externamente requieren conexión a internet.
