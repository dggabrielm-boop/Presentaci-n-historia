# Una isla a 145 km de Florida

Presentación interactiva lista para GitHub Pages.

## Archivos

- `index.html`: estructura principal.
- `style.css`: estética visual inspirada en el modelo HisNS5: documental histórico, collage, rojo/negro/cian, textura grunge y tipografía de alto impacto.
- `app.js`: datos de diapositivas, navegación y preguntas interactivas.
- `assets/`: carpeta para imágenes propias.

## Publicar en GitHub Pages

Subí estos archivos al repositorio, activá GitHub Pages desde `Settings > Pages` y seleccioná `main / root`.
